## Caveats

- Built-in RF / XGBoost importance tends to favour numeric features with many split points (Age, CGPA, cost); permutation importance is the fairer comparison across models.
- Text categories keep every level in Logistic Regression, so compare coefficient sign and size, not exact odds ratios.
- Features that carry the same information share importance; a low score does not prove a factor is unrelated.
- Computed on the training set only (n = 3536); the test set is used only in `src/evaluate.py`.
